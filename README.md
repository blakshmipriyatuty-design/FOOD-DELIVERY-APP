# FOOD-DELIVERY-APP

##  Project Overview

**FoodNest** is a modern food delivery application designed to provide users with a simple, convenient, and enjoyable way to discover restaurants, browse food items, place orders, make secure payments, and track their deliveries.

The application is designed in **Figma** with a clean and attractive user interface inspired by modern food delivery platforms. The design focuses on easy navigation, clear information, attractive food visuals, and a smooth ordering experience.

## Objective

The main objective of the FoodNest application is to create a user-friendly food delivery experience that allows users to:

* Discover nearby restaurants and food items.
* Browse restaurant menus easily.
* Add food items to the cart.
* Manage food quantities before placing an order.
* Select a convenient payment method.
* Confirm orders quickly and easily.
* Track the delivery partner and order status.
* Navigate through the application smoothly.

## Features

* User-friendly and attractive interface.
* Splash screen with FoodNest branding.
* Login and sign-up functionality.
* Restaurant discovery and browsing.
* Restaurant cards with images, ratings, offers, and delivery times.
* Food categories for easy menu navigation.
* Add-to-cart functionality.
* Quantity controls using **+ / −** buttons.
* Cart with item and price details.
* Referral feature: **“Refer a Friend & Earn Up to ₹100.”**
* Multiple payment options.
* Payment details and order summary.
* Order confirmation screen.
* Delivery partner tracking.
* Order status tracking.
* Simple and intuitive navigation.

##  Design Highlights
The FoodNest application focuses on creating a modern, attractive, and user-friendly food delivery experience.

### Colour Palette

* **Vanilla Cream:** `#FFF9F0`
* **Primary Orange:** `#FF6B35`
* **Dark Text:** `#2B2118`
* **Secondary Text:** `#6B6258`
* **White:** `#FFFFFF`

The cream background provides a soft and premium appearance, while orange is used for important actions and highlights.
